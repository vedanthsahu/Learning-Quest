CCDV-F STUDY KIT
Claude Certified Developer - Foundations: handbook + 5 mock exams
=================================================================

HOW TO OPEN
  Double-click  index.html  (Chrome, Edge, Firefox or Safari).
  Nothing to install, no internet needed, no account.

WHAT'S INSIDE
  * Handbook - 18 chapters (orientation + 17 topic chapters), in reading order.
    Start with "How to Use This Handbook".
  * 5 mock exams - 53 questions / 120 minutes each, spread across the
    8 exam domains in the official weightings.
      - "Exam conditions" mode: timer, flag-for-review, a review screen
        before you end the exam, then a score report (estimated scaled
        score out of 1000, PASS/FAIL at 720, performance per domain) and
        every question with its explanation.
      - "Practice" mode: no timer, check each answer as you go.
  * Answer keys - one per set, with an explanation for every question.
  * Printable question papers, if you prefer working on paper.

YOUR PROGRESS
  Chapters you mark as read, exam attempts and scores are saved in your
  browser on this computer. Clearing browser data resets them, and a
  different browser starts fresh.

GOOD TO KNOW
  * These are UNOFFICIAL practice materials written from the published
    exam blueprint. They are not real exam questions.
  * The real exam reports a scaled score (720/1000 to pass) but the
    conversion from raw marks isn't published, so the scaled score here
    is an estimate (72% correct = 720). Aim for 80%+ correct.
  * Facts were checked against Anthropic's documentation as of
    October 2026. The Claude API changes quickly; where something is
    marked "version-dependent", the live docs win.
