# LearningQuest

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The owner uses this local application to study technical handbooks, practise challenges, and build Incident Command AI step by step.

## Product Purpose

Turn learning documents and build plans into actionable chapters, practice, evidence checklists, and persistent progress.

## Operating Context

Existing React/Vite application with a local Python server. Existing books, notes, quizzes, achievements, and project evidence remain authoritative. Do not reset data.json or remove content during redesign.

## Capabilities and Constraints

Preserve current routes and reader deep links, saving and recovery, chapter actions, quizzes, exports, and direct navigation. Scrolling may control cinematic travel; reading and task screens must remain stable. Mobile, keyboard navigation, reduced motion, and unavailable WebGL need usable alternatives.

## Brand Commitments

User explicitly selected the rocket-space journey reference and approved app-wide space redesign. Reuse only assets/code with verified permission and retain attribution. The reference is not a claim of code reuse.

## Evidence on Hand

Handbooks and progress in data.json; imported Incident Command Markdown in content/incident-command; core task definitions in app-src/src/data/incidentProject.js.

## Product Principles

- Actual saved progress, never invented statistics.
- Cinematic exploration is optional; work is always directly reachable.
- Stable, accessible reading and task completion take precedence over decorative motion.
