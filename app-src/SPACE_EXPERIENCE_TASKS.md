# Space experiences — implementation checklist

Approved scope: make the existing space models useful across LearningQuest, while retaining normal reading and progress controls.

- [ ] Architecture station: select a subsystem and open its real build tasks and source documents.
- [ ] Challenge failure lab: experiment with cache, queue pressure and service outages in an explicitly educational simulation.
- [ ] Chapter globe: named section regions and reading-order connections, without inventing prerequisites.
- [ ] Astronaut equipment bay: inspect earned achievements and their requirements/dates in Profile and Achievements.
- [ ] Dashboard rocket dock: reuse the flight rocket and show the saved reading position.
- [ ] Verify desktop, mobile, keyboard access, quiet motion, unavailable WebGL and existing navigation.
- [ ] Independent finish review and implementation handoff.

Guardrails: no real progress writes from simulations or model interactions; no scroll hijacking; no paid services; no replacement of the existing flight. The astronaut is the existing credited model, not a personal likeness. A likeness requires user-provided reference photos and a separate modeling workflow.
