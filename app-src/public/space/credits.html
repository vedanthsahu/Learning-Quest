Flight credits

LearningQuest's home flight is an illustrative learning journey, not an astronomical simulation. It was adapted, with the owner's direction, from an existing open project; the credits below list where the code and every shipped asset come from.

  • Scene code and interaction design: adapted from Jordan Perez's space-portfolio (live site), which itself credits Abhishek Badar's rocket portfolio. The camera rig, rocket, planets, environment, skill/project cards, sun-impact finale, scroll engine and HUD overlays were ported to this app and refitted with LearningQuest content. Neither repository publishes a licence file; all rights in that code remain with its authors.
  • Planet, moon, sun and Milky Way textures: Solar System Scope, licensed under CC BY 4.0, in the WebP versions distributed with the space-portfolio.
  • HDRI lighting: “Dikhololo Night”, Poly Haven (CC0).
  • Astronaut and spaceship models: Quaternius (CC0).
  • ISS model: NASA 3D Resources (public domain; no NASA endorsement implied).
  • Fonts: Space Grotesk, Inter and JetBrains Mono via Fontsource (SIL Open Font License 1.1). Barlow Condensed SemiBold for the orbital theme headings, SIL Open Font License 1.1.
  • Libraries: Three.js, React Three Fiber, drei, postprocessing, Lenis, zustand, Framer Motion and Tailwind CSS (all MIT).
